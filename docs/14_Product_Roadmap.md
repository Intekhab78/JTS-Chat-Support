# Product Roadmap

Related documents: [Feature Matrix](05_Feature_Matrix.md), [Production Readiness](11_Production_Readiness.md), [CTO Master Report](15_CTO_Master_Report.md).

## Version 1.0

Goal: production-safe core SaaS helpdesk + CRM.

- Fix P0 security issues.
- Complete knowledge-base API or remove feature from release.
- Harden billing and disable mock checkout.
- Add integration tests for auth, tenant isolation, CRM, tickets, invoices, procurement.
- Add pagination/indexes.
- Add deployment runbook, backups, monitoring.

## Version 1.5

Goal: complete operational CRM/accounting workflows.

- Quote-to-invoice conversion.
- Invoice payment lifecycle.
- Receipts, credit notes, refunds.
- Email templates.
- Reminder engine.
- Customer/supplier statements.
- Import/export jobs.
- Webhook retry UI.

## Version 2.0

Goal: broader ERP operations.

- Tax/GST engine.
- Financial year and number series.
- Sales orders.
- Purchase returns and sales returns.
- Stock reservation.
- Inventory valuation.
- P&L and cash-flow reports.
- Branch management.

## Enterprise Edition

- Advanced RBAC matrix.
- Approval workflows.
- Audit retention controls.
- SSO.
- API key management.
- Dedicated tenant branding.
- SLA policy builder.
- Data export compliance tools.
